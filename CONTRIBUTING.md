# Contributing to YEARCORE

YEARCORE is a small, dependency-free web app. Contributions are welcome.

## Run locally

```bash
git clone https://github.com/IlyaBOT/yearcore.git
cd yearcore
python -m http.server 8080
```

Open <http://localhost:8080>.

## Before submitting a change

1. Keep the site deployable as plain static files on GitHub Pages.
2. Do not introduce a mandatory backend, API key or compilation step.
3. Verify desktop and mobile layouts.
4. Test poster, tier list, bingo, JSON import/export and PNG export.
5. Do not submit copyrighted assets without rights or adequate permission.

Use GitHub Issues for bugs or feature suggestions, then send a pull request
with an explanation and screenshots if the UI changes.
